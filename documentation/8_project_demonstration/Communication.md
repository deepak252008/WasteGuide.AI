# Communication

This document outlines the elevator pitch and messaging frameworks used to communicate the value of WasteGuide AI to civic stakeholders and evaluators:

## 1. The 30-Second Elevator Pitch
> "Did you know that over 60% of recyclable materials in Hyderabad end up in landfills simply because residents are confused about local recycling categories? **WasteGuide AI** solves this problem. It is a dark-green, terminal-inspired civic dashboard that gives residents immediate, step-by-step instructions on how to recycle any object. It uses Llama 3.3 to classify waste, automatically maps nearby free specialized collection points, and tracks recycling progress. Best of all, it has zero operational mapping costs and features an offline Demo Mode for instant testing."

---

## 2. Stakeholder Messaging Matrix

| Stakeholder Group | Core Value Message | Focus Metrics |
| :--- | :--- | :--- |
| **Municipal Officials (GHMC)** | Decreases landfill overload by encouraging segregation at source. | Landfill tonnage reduction, hazardous waste prevention. |
| **Local Residents** | Demystifies confusing segregation rules with an easy search input. | Time saved, convenience, distance to local drop points. |
| **Academic Evaluators** | Demonstrates solid full-stack architecture, clean separation of concerns, and API fallbacks. | Feature completion, code layout, test suite passes. |
