# Project Demo Planning

This document details the scheduling, timing, and slide-deck blueprint designed for the 5-minute academic presentation pitch:

## 1. Demo Schedule & Timing (Total: 5 Minutes)

- **0:00 - 0:45 (Introduction & Pain Points)**:
  - Outline segregation confusion in Hyderabad. Present the elevator pitch.
- **0:45 - 2:00 (Core Feature Demo - Scan & AI)**:
  - Screen-share the Home portal. Scan "Battery". Highlight warning cards, categories, and step-by-step instructions.
- **2:00 - 3:15 (Map Locator & Filters)**:
  - Select "Ramky Hazardous Facility". Show map zooming and contact details.
- **3:15 - 4:00 (Logs & Dashboard)**:
  - Show real-time history filtering. Load Chart.js canvases on the Dashboard.
- **4:00 - 5:00 (Architecture, Scalability & QA)**:
  - Explain the Flask-React decoupled architecture, cost efficiency (OSM tiles), and open the floor for questions.

## 2. Slide-Deck Blueprint

- **Slide 1: Title Slide**: WasteGuide AI - Sustainable Waste Management Assistant using Generative AI.
- **Slide 2: Problem Statement**: Household segregation confusion, landfill overloading, water pollution.
- **Slide 3: Proposed Solution**: Dark green civic portal combining AI guides, Leaflet Maps, and Habit analytics.
- **Slide 4: Technology Architecture**: React + Vite -> Flask -> Groq API (Llama 3.3) / Firestore / OpenStreetMap.
- **Slide 5: Scalability & Future Plan**: Camera scanning, gamified rewards, and municipality admin panels.
- **Slide 6: Conclusion**: Thank You & QA.
