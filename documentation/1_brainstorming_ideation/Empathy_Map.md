# Empathy Map

Below is the Empathy Map developed for our target user, an **Urban Resident (Hyderabad)**:

| Category | Description |
| :--- | :--- |
| **SAYS** | - "Is this plastic tray recyclable?"<br/>- "I want to recycle my old phone charger, but I don't know where to take it."<br/>- "Segregating waste is too confusing; there are too many rules." |
| **THINKS** | - "Will my effort make any difference to the landfill?"<br/>- "Is it safe to throw medicine bottles in the regular bin?"<br/>- "I wish there was a single dashboard that gave me answers instantly." |
| **DOES** | - Searches Google for local waste rules and gets mixed results.<br/>- Taps on quick items or searches on online forums.<br/>- Drops off common plastic bottles in blue bins but dumps electronics in general trash. |
| **FEELS** | - **Guilty** about throwing hazardous items in General Waste.<br/>- **Confused** by local segregation regulations.<br/>- **Motivated** when they see their recycling stats increase. |

---

## Pain Points (Pains)
- Mixed regulations on plastic and paper recycling.
- Travel distance to specialized waste stations.
- Lack of immediate visual verification or feedback.

## Gain Points (Gains)
- Quick text search classification.
- Clear map indicators of collection centers with distances.
- Dashboard graphs highlighting personal recycling rates.
