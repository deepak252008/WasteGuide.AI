# Brainstorming & Idea Prioritization

## 1. Ideation Brainstorming
To tackle the issue of domestic waste segregation, the team brainstormed multiple features for our civic application:
- **Feature A (AI Photo Scan)**: Take or upload a photo of trash and let AI categorize it. (High effort, requires camera API / image processing).
- **Feature B (Text Search waste classifier)**: Quick search input box for naming trash. (Medium effort, fast response).
- **Feature C (Regional Map Locator)**: Filterable Leaflet map displaying municipal collection points. (Medium effort, high impact).
- **Feature D (Residents Scanning Log)**: A page tracking items scanned. (Low effort, important for context).
- **Feature E (Analytics Dashboard)**: Bar, Line, and Doughnut charts tracking user recycling habits over time. (Medium effort, extremely high visual impact).
- **Feature F (Gamified Eco-Badges / Rewards)**: Residents earn discount coupons for local stores. (High effort, requires payment flows / integrations).

## 2. Prioritization Matrix

We scored the brainstormed features on **Impact vs Effort (scale of 1-10)** to select our MVP scope:

| Feature | Impact (1-10) | Effort (1-10) | Priority / Scope |
| :--- | :---: | :---: | :--- |
| **Text Search Waste Classifier** | 9 | 4 | **Core MVP (Selected)** |
| **Regional Map Locator** | 9 | 5 | **Core MVP (Selected)** |
| **Residents Scanning Log** | 7 | 3 | **Core MVP (Selected)** |
| **Analytics Dashboard** | 8 | 5 | **Core MVP (Selected)** |
| **AI Photo Scan** | 8 | 8 | Future Release |
| **Gamified Eco-Badges / Rewards** | 6 | 9 | Future Release |

By prioritizing high-impact, medium-effort features, we selected the **Text-based Waste Scanner, Collection Centers Map, History Log, and Analytics Dashboard** for the WasteGuide AI application scope.
